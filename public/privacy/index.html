2. Qué hace Quasaric con tu música

La aplicación web procesa en el navegador de tu dispositivo los archivos de audio que eliges, las pistas separadas, las notas MIDI, los acordes, las tablaturas y los datos de tu biblioteca. Estos contenidos se guardan en el almacenamiento local del navegador o dispositivo. La aplicación no los envía a los servidores de Quasaric ni los sube para que Quasaric los procese.

La separación y el análisis se ejecutan localmente con modelos descargados. La ejecución local no significa que toda conexión de red sea anónima: al solicitar la web o descargar un modelo, el servidor correspondiente recibe los datos técnicos habituales de una conexión HTTP.

3. Datos técnicos y proveedores

  • Alojamiento de la web: Quasaric se distribuye mediante Azure Static Web Apps. Al cargar páginas y recursos, la infraestructura puede tratar la dirección IP, fecha y hora, URL/recurso solicitado, información del navegador y datos técnicos necesarios para entregar el servicio, mantener su seguridad y diagnosticar errores. La conservación de registros depende de la configuración y condiciones del proveedor.
  • Descarga de modelos: los modelos de IA se descargan desde Hugging Face cuando el usuario inicia esa descarga. El proveedor recibe la solicitud y los datos técnicos de conexión asociados. Los archivos de audio seleccionados por el usuario no se envían a Hugging Face para su procesamiento por Quasaric.
  • Enlaces externos: si abres GitHub u otro enlace, pasarás a un servicio de terceros sujeto a sus propias políticas.

Quasaric no incorpora herramientas propias de analítica, píxeles publicitarios ni seguimiento entre sitios. La ubicación de los centros de datos, los plazos de conservación de registros y las garantías de transferencias internacionales deben comprobarse en la configuración y contratos vigentes de cada proveedor; no se presume que todos los datos permanezcan en el Espacio Económico Europeo.

4. Finalidades y bases jurídicas

  • Prestar y mantener la web y sus funciones, atender solicitudes iniciadas por el usuario y permitir la descarga de recursos: ejecución del servicio solicitado y, cuando corresponda, interés legítimo en mantener la disponibilidad y seguridad del sitio.
  • Atender consultas y solicitudes de derechos: cumplimiento de obligaciones legales.
  • El almacenamiento local de preferencias, biblioteca y modelos se utiliza para las funciones que el usuario solicita o configura en su dispositivo.

Quasaric no utiliza los archivos musicales para publicidad, perfilado ni entrenamiento de modelos propios.

5. Conservación

Quasaric no mantiene una cuenta ni una biblioteca musical centralizada. Los archivos, resultados y preferencias permanecen en el almacenamiento local hasta que el usuario los borre o desinstale/limpie los datos del navegador. Los registros técnicos que puedan generar los proveedores de infraestructura se conservan conforme a sus políticas y a la configuración aplicable.

Escribe a [[EMAIL DE CONTACTO]] e identifica la solicitud; solo se pedirán datos adicionales cuando sean necesarios para verificar la identidad. También puedes reclamar ante la Agencia Española de Protección de Datos (www.aepd.es).

7. Menores

Quasaric no solicita deliberadamente datos personales de menores ni ofrece registro de cuentas. Si consideras que se han facilitado datos personales de un menor, contacta con el responsable usando los datos indicados en el aviso legal.

8. Seguridad y cambios

Se aplican medidas técnicas razonables para proteger la web y su distribución. Ningún sistema conectado a Internet puede garantizar seguridad absoluta. Esta política podrá actualizarse para reflejar cambios reales en el servicio, proveedores o normativa; se indicará la fecha de revisión.
